# Kalita

A Windows/Linux/Android rewrite of the abandoned X-Cash 2.1 budgeting app, compatible in place with its original `Data.mdb` (Jet4 / Access 2000) database.

Kotlin core shared between a Qt Widgets desktop UI (QtJambi) and a Jetpack Compose Android UI (F-Droid), with Nextcloud sync and agent/MCP integration.
