# ADR-0001: GPL-3.0-only project license

- Status: Accepted
- Date: 2026-10-10
- See also: dev_plan.md §13.1

## Context

Kalita is a from-scratch rewrite of a proprietary program (X-Cash), reusing only its file format
and functional ideas, never its code, text, icons, or demo data (§16.3). It needs a license that
(a) keeps any distributed fork or build free, (b) is compatible with the dependencies already
chosen — in particular Jackcess and most of the Android/Kotlin ecosystem (Apache-2.0), and
**Qt Charts**, which ships only under GPLv3 or a commercial license, never LGPL — and (c) is
accepted by F-Droid, which needs the full source and a recognized free license.

## Decision

License the project under **GPL-3.0-only** — not GPL-2.0, and not "GPL-3.0-or-later". Apache-2.0
(most dependencies) is compatible with GPLv3 but not GPLv2, which rules out v2. "Or-later" would
commit the project to terms of future GPL versions sight unseen; a fixed version can only be
changed later with the agreement of everyone who has contributed code (contributions come in under
DCO, without a copyright transfer that would let one party relicense unilaterally).

## Consequences

- Every distributed fork and derivative stays free (copyleft); this also satisfies Qt Charts'
  licensing requirement without needing a commercial Qt license.
- Dependencies are restricted to licenses compatible with GPL-3.0-only (table in dev_plan.md
  §13.1); CI's `supply-chain` job enforces this on every PR once it exists (dev_plan.md 13.3).
- Every file carries an SPDX header and the repository passes `reuse lint` (REUSE spec 3.3).
- Upgrading past GPL-3.0 later needs explicit agreement from all contributors, not just a version
  bump in the license file.
