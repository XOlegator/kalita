# Руководство пользователя Kalita

Это руководство — для тех, кто пользуется Kalita, а не разрабатывает её (для разработки и вклада
в проект см. [`AGENTS.md`](../../AGENTS.md) и [`CONTRIBUTING.md`](../../CONTRIBUTING.md)).
Написано по-русски сознательно, в отличие от остальной документации репозитория — интерфейс
самой Kalita целиком на русском, и это руководство его описывает.

Kalita — открытая (GPL-3.0-only) программа семейного бюджета, совместимая по формату базы
(`Data.mdb`) с оригинальным X-Cash: один и тот же файл базы можно открывать то в Kalita, то в
оригинальном X-Cash (например, под Wine), без конвертации.

## Установка

### Kubuntu/Ubuntu 24.04 и 26.04 (рекомендуемый способ)

Удобнее всего — через личный PPA автора:

```sh
sudo add-apt-repository ppa:xolegator/packages
sudo apt update
sudo apt install kalita
```

Дальше `kalita` ставится и обновляется как любой другой пакет `apt`.

### AppImage или `.tar.gz` (без PPA, любой Linux x86_64)

На странице [GitHub Releases](https://github.com/XOlegator/kalita/releases) у каждого релиза
есть `Kalita-x86_64.AppImage` и `Kalita-<версия>-linux-x86_64.tar.gz`.

- **AppImage**: скачать, сделать исполняемым (`chmod +x Kalita-x86_64.AppImage`) и запустить —
  установка не нужна.
- **`.tar.gz`**: распаковать куда угодно (`tar xf Kalita-*.tar.gz`) и запустить
  `./Kalita/AppRun` — подходит, когда AppImage по каким-то причинам не монтируется (например,
  FUSE недоступен).

Оба варианта несут собственный Qt и Java-рантайм внутри — системные версии не используются и не
мешают.

### Windows

На странице релизов есть установщик `Kalita-<версия>.msi` и портативный
`Kalita-<версия>-windows-x64.zip`. Проверено сборкой в CI на чистых образах Windows 10/11; в этом
сеансе работы отдельно вручную не перепроверялось — если что-то не так, заведите issue.

## Первый запуск

При первом запуске (или если сохранённый путь к базе не найден) Kalita предложит выбрать файл
базы — либо существующий `Data.mdb` от X-Cash, либо создать новый. Выбор запоминается: при
следующем запуске Kalita сама откроет ту же базу.

Рядом с файлом базы Kalita заводит папку `<имя-базы>.kalita-data/` — в ней резервные копии
(`backups/`, создаются перед каждой записью) и журнал изменений (`history.jsonl`, то же самое,
что показывает панель «История изменений» в самой программе). Эту папку не нужно трогать вручную
и можно не держать под синхронизацией отдельно от самой базы.

## Главное окно

Строка меню: **Файл**, **Справочники**, **Журналы**, **Фильтр**, **Вид**, **Агенты**, **Справка**.

- **Файл** — открыть базу, список недавних, закрыть текущую базу, выход.
- **Справочники** — счета, «Кто/кому» (контрагенты), валюты, статьи бюджета (дерево), курсы валют.
- **Журналы** — журнал «Доходы/Расходы» и «История изменений».
- **Фильтр** / **Вид** — см. ниже.
- **Агенты** — подключения для ИИ-агентов (MCP/CLI), см. [`docs/agents/`](../agents/README.md).

Панели (Остатки, История, Информация, Фильтр, Быстрый фильтр) — стыкуемые: их можно перетаскивать,
закрывать, перемещать между зонами окна. Раскладка окна и панелей запоминается при закрытии и
восстанавливается при следующем запуске — отдельно для журнала и для каждого справочника.

## Журнал «Доходы/Расходы»

Таблица операций с вычисляемыми колонками (Сумма со знаком, Курс, Сумма в пересчёте для выбранной
валюты приведения) и подвалом-агрегатом (Сумма/Мин/Макс/Среднее/Количество по выделенным ячейкам).

- **Добавить операцию** — `Insert`, или кнопка на тулбаре.
- **Изменить** — `Ctrl+Enter`.
- **Удалить** (мягкое, с возможностью восстановить) / **показать удалённые** — `Ctrl+Delete` /
  `Ctrl+Shift+D`.
- Заголовки колонок — клик сортирует, Shift+клик добавляет колонку ко множественной сортировке
  (уровень и направление показаны значком `▲`/`▼` с номером в заголовке); колонки можно
  перетаскивать и закреплять слева (контекстное меню заголовка).

### Поиск, фильтр, виды

- `Ctrl+F` / `F3` — быстрый поиск по журналу с переходом по совпадениям.
- Строка поиска в тулбаре — фильтрация по подстроке сразу по всем колонкам.
- Панель **«Фильтр»** — полноценный фильтр по дате (в т.ч. «Текущий месяц»/квартал/год),
  справочникам, сумме, комментарию, с флажками «Пустые»/«Инверсия» на каждом поле; `F8` сбрасывает
  фильтр.
- Панель **«Быстрый фильтр»** — отдельные условия, вынесенные из основного фильтра кнопкой
  «В быстрый фильтр» (`Ctrl+Q`), можно переключать по одному не трогая основной фильтр.
- Фильтры можно сохранять и подгружать по имени, в т.ч. в «Избранное».
- **Именованные виды** журнала (набор видимых/закреплённых колонок + сортировка + фильтр +
  валюта приведения разом) — `Alt+S` сохранить, `Alt+L` загрузить.
- `Ctrl+D` — диалог видимости столбцов.

## Справочники

Счета, «Кто/кому» и валюты — плоские списки с поиском и показом/скрытием удалённых. Дерево статей
бюджета — с перемещением вверх/вниз (`Ctrl+↑`/`Ctrl+↓`), вырезать/вставить (`Ctrl+X`/`Ctrl+V`,
`Ctrl+Alt+V` — вставить в корень), подсчётом ссылающихся операций перед удалением. Курсы валют —
таблица с фильтром по валюте и диапазону дат. Во всех списках: `Ctrl+Enter` — изменить,
`Ctrl+Delete` — удалить, `Ctrl+Shift+D` — показать удалённые.

## Остатки, История, Информация

- **Остатки** — таблица «счёт / валюта / получено / потрачено / остаток» с ИТОГО в валюте
  приведения; отрицательные остатки — красным.
- **История изменений** — кто, когда и что менял (из `history.jsonl`), в обратном хронологическом
  порядке.
- **Информация** — карточка выбранной в журнале строки со всеми её полями.

`F5` обновляет все панели сразу (например, после правки из другого процесса — см. ниже).

## Если база уже открыта в другом месте

Kalita блокирует файл базы на время работы (`<имя>.kalita.lock` рядом с базой — не редактируйте
и не удаляйте его вручную, пока Kalita запущена). Если ту же базу параллельно открывает подключённый
ИИ-агент (`kalita mcp`/CLI) в режиме записи — правки передаются уже открытому окну напрямую и
появляются в журнале без `F5`, без необходимости закрывать и переоткрывать базу.

## Подключение ИИ-агентов

Kalita умеет работать с ИИ-агентами (Claude Desktop, Claude Code, и другими через MCP) — вносить
операции по описанию, разносить чек по статьям и т. п., всегда с предпросмотром и подтверждением
перед записью. Настройка подключений — меню **Агенты → Подключения…** в самой программе; подробная
инструкция для разных клиентов — в [`docs/agents/`](../agents/README.md).

## Совместимость с X-Cash

Kalita читает и пишет тот же файл `Data.mdb`, что и оригинальный X-Cash — его можно открывать то
одной программой, то другой, без конвертации и экспорта. Если вы ведёте базу годами в X-Cash —
просто откройте тот же файл в Kalita.
